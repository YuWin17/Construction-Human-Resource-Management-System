# 建筑人力资源人才录入系统

## 1. 文档目的

本文档定义建筑人力资源中介公司人才录入系统第一版（MVP）的业务范围、功能规则和验收标准。

第一版目标是让管理员能够集中维护建筑行业人才档案、行业证书、签约信息及合同附件，并在合同和证书临近到期时获得可处理的提醒。

## 2. 项目范围

### 2.1 本期用户

- 管理员：系统唯一角色，拥有全部数据的查看、新增、编辑、删除、导出和系统配置权限。

### 2.2 本期核心能力

- 管理人才基本档案。
- 管理人才持有的行业证书。
- 管理人才签约状态和签约合同。
- 根据可配置的提前天数生成合同和证书到期提醒。
- 上传、下载和管理合同附件。
- 配置证书名称字典，并支持录入时即时新增证书名称。
- 按常用条件检索、筛选和导出人才数据。
- 通过仪表盘了解人才、证书和合同的当前情况。
- 保留关键业务操作记录，便于管理员追溯。

### 2.3 本期不包含

- 多角色、组织架构、数据权限和审批流。
- 候选人门户、移动端 App、短信、邮件或微信通知。
- 电子合同签署与 OCR 识别。
- 薪酬、社保、考勤、项目派工和财务结算。
- 与第三方招聘、证书查询或政府平台的实时对接。

## 3. 业务对象和字段

### 3.1 人才档案

每位人才对应一份唯一档案。身份证号是业务主标识，录入时必须校验唯一性。

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 姓名 | 是 | 2 至 50 个字符 |
| 身份证号 | 是 | 18 位身份证格式；全系统唯一；列表中默认脱敏展示 |
| 性别 | 否 | 男、女、未知；可由身份证号辅助推导，但允许人工调整 |
| 出生日期 | 否 | 可由身份证号辅助推导，允许人工调整 |
| 手机号 | 是 | 中国大陆手机号格式；可用于联系人才 |
| 籍贯 | 否 | 省、市、区县或文本地址 |
| 现居地 | 否 | 省、市、区县或文本地址 |
| 学历 | 否 | 初中及以下、高中/中专、大专、本科、硕士及以上、其他 |
| 专业 | 否 | 最高学历对应专业 |
| 从业年限 | 否 | 非负整数，单位为年 |
| 求职/合作意向 | 否 | 可多选：全职、兼职、证书挂靠、项目合作、其他 |
| 期望地区 | 否 | 可多选或文本补充 |
| 备注 | 否 | 最多 1,000 个字符 |
| 档案状态 | 是 | 在库、暂停合作、已归档；默认在库 |
| 创建时间 | 系统生成 | 不可编辑 |
| 更新时间 | 系统生成 | 不可编辑 |

身份证号与手机号属于敏感信息：列表默认展示为脱敏值；只有在人才详情和编辑页显示完整值。第一版不实现字段级权限，但应为后续扩展保留清晰的展示边界。

### 3.2 行业证书

一位人才可以拥有多本证书。证书作为人才档案的从属信息，在人才详情页维护。

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 证书名称 | 是 | 从管理员配置的证书名称列表选择；选择“录入新证书名”时可新增名称并自动选中 |
| 证书类别 | 是 | 注册类、职称类、岗位类、安全类、技能类、其他 |
| 专业/方向 | 否 | 例如：建筑工程、市政公用工程、机电工程 |
| 证书编号 | 否 | 同一人才下不得重复 |
| 发证机构 | 否 | 例如：住房和城乡建设主管部门 |
| 发证日期 | 否 | 日期 |
| 有效期至 | 否 | 日期；填写后参与证书到期提醒计算 |
| 注册状态 | 是 | 有效、待注册、已注册、已注销、已过期；默认有效 |
| 注册单位 | 否 | 人才当前注册的单位 |
| 是否可用 | 是 | 是、否；默认是 |
| 备注 | 否 | 最多 500 个字符 |

### 3.3 签约合同

人才当前签约状态由有效合同决定。一个人才可以保留多份历史合同，但任意时刻最多只能有一份“履约中”合同。

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 合同编号 | 是 | 全系统唯一；可手动输入或由系统生成 |
| 签约单位 | 是 | 人才实际签约的单位名称 |
| 合同类型 | 是 | 劳动合同、劳务协议、合作协议、证书服务协议、其他 |
| 合同开始日期 | 是 | 日期 |
| 合同结束日期 | 是 | 必须晚于开始日期 |
| 合同状态 | 是 | 履约中、已到期、已解除、已续约；新增默认履约中 |
| 签约备注 | 否 | 最多 1,000 个字符 |
| 合同附件 | 否 | 支持上传一到多份文件；用于保存合同扫描件或相关材料 |
| 创建时间 | 系统生成 | 不可编辑 |
| 更新时间 | 系统生成 | 不可编辑 |

人才的签约状态为系统计算字段：存在履约中且当前日期位于合同起止日期范围内的合同，即显示“已签约”；否则显示“未签约”。管理员不能直接在人才表单中随意修改该状态。

#### 3.3.1 合同附件

- 管理员可在新增或编辑合同期间上传一个或多个附件，也可在合同详情中追加或删除附件。
- 支持 PDF、JPG、JPEG、PNG、DOC、DOCX、XLS、XLSX 文件；单个文件大小及单份合同附件数量上限在技术设计阶段确定。
- 上传后保存原始文件名、文件大小、上传时间和上传人；支持下载。
- 图片和 PDF 可在浏览器中预览；Office 文件提供下载打开，不承诺在线预览。
- 删除合同附件必须二次确认，并写入操作日志。

### 3.4 到期提醒

系统为“履约中”合同和填写了有效期至的证书生成独立待办提醒。

| 字段 | 说明 |
| --- | --- |
| 提醒对象 | 一份履约中合同，或一条带有效期至的证书 |
| 提醒类型 | 合同到期、证书到期 |
| 提醒开始时间 | 到期日期减去对应的系统配置提前提醒天数 |
| 合同默认提前天数 | 30 天 |
| 证书默认提前天数 | 30 天 |
| 可配置范围 | 1 至 365 天，管理员可分别配置合同和证书的提醒天数 |
| 提醒级别 | 正常提醒、即将到期、已到期 |
| 提醒状态 | 待处理、已处理、已忽略 |
| 处理方式 | 标记已处理、忽略、进入关联合同或证书详情执行续约、更新、注销等操作 |

提醒状态仅影响待办列表，不改变合同或证书状态。合同或证书到期后，系统在管理员登录或访问相关页面时更新相关展示状态；第一版不依赖外部消息推送。

## 4. 功能需求

### 4.1 管理员登录

- 系统提供管理员账号和密码登录。
- 未登录用户不能访问系统业务页面。
- 管理员可以退出登录。
- 第一版只初始化一个管理员账号；账号创建、重置密码和多管理员管理不纳入本期业务界面。

### 4.2 仪表盘

仪表盘为管理员登录后的首页，展示当日工作概览：

- 人才总数。
- 在库人才数。
- 已签约人才数。
- 未签约人才数。
- 即将到期合同数和已到期合同数。
- 即将到期证书数和已到期证书数。
- 最近新增人才列表。
- 待处理到期提醒列表，包含合同和证书提醒。

统计数据支持点击进入对应的筛选列表。

### 4.3 人才列表

- 分页展示人才档案。
- 默认按更新时间倒序排列。
- 展示姓名、脱敏身份证号、手机号、主要证书、签约状态、档案状态、更新时间和操作入口。
- 支持按姓名、身份证号、手机号关键字搜索。
- 支持按签约状态、档案状态、证书名称/类别、证书可用状态、现居地筛选。
- 支持组合筛选、重置筛选和分页。
- 支持新增人才、查看详情、编辑、归档、删除和导出当前筛选结果。
- 删除为物理删除：管理员须在二次确认弹窗中明确确认，系统随后删除人才档案、关联证书、合同、附件和提醒；操作日志保留删除审计记录，但不保留已删除人才的敏感字段。

### 4.4 人才新增与编辑

- 新增人才时录入基本信息，可同时录入零到多条证书信息。
- 保存前校验姓名、身份证号、手机号等必填项和格式。
- 身份证号重复时阻止提交，并提示已存在档案。
- 编辑时展示完整敏感字段，保存后更新人才档案和关联证书。
- 已归档人才不可新建履约中合同；恢复在库后可继续维护。

### 4.5 人才详情

详情页包含以下分区：

- 基本资料：完整展示人才基本信息和签约状态。
- 证书信息：证书列表，支持新增、编辑、删除单条证书。
- 合同信息：合同历史及附件，支持新增合同、编辑合同、上传/下载/删除附件、续约、解除合同。
- 操作记录：展示人才创建、编辑、合同状态变化、提醒处理等关键记录。

### 4.6 合同管理

- 支持从人才详情页创建合同。
- 保存“履约中”合同时，系统校验该人才不存在其他履约中合同；若存在，提示管理员先续约、解除或修改原合同状态。
- 合同结束日期不得早于或等于开始日期。
- 续约操作应保留原合同历史，并创建一份新的履约中合同。
- 解除操作要求填写解除日期和解除原因，合同状态更新为已解除。
- 到期合同可查看、续约或标记为已处理；不允许继续编辑为履约中，除非通过续约创建新合同。
- 合同表单和合同详情支持附件上传、下载、图片/PDF 预览及删除；附件删除需要二次确认。

### 4.7 到期提醒中心

- 展示合同和证书到期提醒，默认仅显示待处理提醒。
- 支持按提醒类型、提醒级别、提醒状态、到期日期范围筛选。
- 每条合同提醒显示人才姓名、签约单位、合同类型、结束日期、剩余/逾期天数和当前处理状态。
- 每条证书提醒显示人才姓名、证书名称、证书类别、有效期至、剩余/逾期天数和当前处理状态。
- 支持单条或批量标记已处理、忽略。
- 点击提醒可跳转到人才详情对应的合同或证书页签。
- 提醒中心顶部显示待处理总数，并按合同/证书和提醒级别划分数量。

提醒级别规则：

| 条件 | 级别 |
| --- | --- |
| 合同或证书已到期 | 已到期 |
| 剩余天数小于等于 7 天 | 即将到期 |
| 已进入对应提醒窗口且剩余天数大于 7 天 | 正常提醒 |

### 4.8 数据导出

- 管理员可导出当前人才列表的筛选结果为 Excel 或 CSV。
- 导出字段包括人才基本信息、签约状态和证书摘要；身份证号和手机号以完整值导出。
- 导出前明确提示文件包含完整身份证号和手机号，管理员确认后才能生成导出文件。
- 导出操作记录在操作日志中。

### 4.9 系统设置

第一版包含提醒设置和证书名称配置：

- 分别设置合同到期、证书到期的提前提醒天数。
- 每个提醒天数的输入范围为 1 至 365 天。
- 保存后立即影响提醒列表和仪表盘统计。
- 维护证书名称字典：支持新增、编辑、停用和排序常用证书名称。
- 人才录入表单的证书名称下拉列表使用启用状态的字典项，最后固定提供“录入新证书名”选项。
- 选择“录入新证书名”后，管理员填写名称并保存，该名称自动加入证书字典并处于启用状态。
- 已被人才证书引用的名称不得物理删除，只能停用；停用后不再出现在新增证书的下拉列表中，但历史数据保留原名称。
- 页面展示各项设置的最后修改时间。

### 4.10 操作日志

- 自动记录人才新增、编辑、归档/恢复、删除、证书变更、合同新增/编辑/续约/解除、合同附件变更、提醒处理、设置与证书名称字典变更和数据导出。
- 日志字段包含操作时间、操作人、操作类型、业务对象、对象名称/编号和变更摘要。
- 管理员可按操作类型、对象类型、日期范围查询日志。

## 5. 页面与导航

一级导航：

- 仪表盘
- 人才管理
- 到期提醒
- 操作日志
- 系统设置

人才详情为人才管理的二级页面，不在一级导航中单独出现。

## 6. 关键业务规则

1. 身份证号全局唯一；人才被物理删除后，其身份证号可重新建立档案。
2. 一个在库人才可有多本证书和多份历史合同。
3. 同一人才同一时间只允许一份履约中合同。
4. 签约状态从有效合同计算，不允许手工覆盖。
5. 合同和证书提醒天数为两项独立的全局配置，修改后立即重新计算应显示的提醒。
6. 提醒状态不替代合同或证书状态；处理提醒不会自动续约、解除或变更证书。
7. 归档人才保留历史数据和操作日志，但不参与默认在库人才统计。
8. 物理删除人才需要二次确认；删除时同步删除关联证书、合同、附件及未完成提醒，并保留去敏后的删除审计记录。
9. 已被引用的证书名称字典项只能停用，不能物理删除。
10. 日期计算以系统部署时区为准，第一版默认使用中国标准时间（UTC+8）。

## 7. 非功能需求

### 7.1 易用性

- 常用操作不超过三次点击可完成：新增人才、查看待到期合同、处理提醒。
- 表单必须提供明确的必填标识、格式提示和错误反馈。
- 列表支持空状态、加载状态和操作成功/失败反馈。

### 7.2 性能

- 第一版目标数据量：10 万人才档案、每人最多 20 条证书、20 份历史合同。
- 常规列表查询和筛选在正常网络环境下应在 2 秒内返回。
- 导出大量数据时采用异步任务或限制单次导出规模，具体方案在技术设计阶段确定。

### 7.3 安全与数据保护

- 登录密码必须安全存储，不保存明文密码。
- 业务接口必须校验登录状态。
- 身份证号和手机号在列表默认脱敏。
- 关键操作应写入审计日志。
- 导出完整敏感字段前必须显示风险提示并要求管理员确认。
- 合同附件下载接口必须校验登录状态，文件存储不应直接公开访问。
- 定期备份数据库和合同附件的策略在部署方案中明确。

### 7.4 浏览器与终端

- 支持当前主流桌面浏览器：Chrome、Edge。
- 第一版优先适配桌面端管理场景；移动端至少可查看，不承诺完整高效录入体验。

## 8. 验收标准

1. 管理员可登录并退出系统。
2. 管理员可新增、编辑、归档、删除和查询人才；身份证号重复时不能保存，删除后二次建档允许使用原身份证号。
3. 管理员可为人才维护多条证书，可从证书名称字典选择或即时新增名称，并能按证书条件筛选人才。
4. 管理员可创建、续约、解除合同、上传和下载合同附件，并能查看合同历史。
5. 人才签约状态能随有效合同正确变化。
6. 系统可根据各自配置的提前天数展示合同和证书到期提醒，并正确区分正常提醒、即将到期和已到期。
7. 管理员可处理或忽略提醒，且处理记录可追溯。
8. 管理员可导出当前筛选条件下的人才数据；确认后导出完整身份证号和手机号。
9. 管理员可修改合同和证书提醒天数，并维护证书名称字典；仪表盘和提醒中心随之更新。
10. 关键操作能够在操作日志中查询到。

## 9. 已确认决策

1. 导出文件包含完整身份证号和手机号，导出前必须明确提示并二次确认。
2. 合同支持上传、下载、预览（PDF/图片）和删除附件。
3. 合同与证书均生成到期待办提醒，提醒天数可分别配置。
4. 人才档案支持物理删除，删除前必须二次确认，并保留去敏审计记录。
5. 证书名称由管理员配置；录入时以下拉选项提供，列表最后一项固定为“录入新证书名”，新增名称后自动保存到字典。
6. 合同附件限制为单文件最大 20 MB、每份合同最多 10 个附件，支持 PDF、图片和常见 Office 文档。
7. 人才物理删除不可恢复，第一版不提供回收站。
8. 合同和证书提醒默认均提前 30 天，并允许在系统设置中分别修改。

## 10. V2：企业库与送证单

### 10.1 人才库补充字段

在既有人才基本档案和证书信息之外，人才库新增以下业务字段：人才编号（系统生成、可检索）、登记/最后更新时间、人才持证执业（职业）、专业、薪资年限（支持“金额/周期”文本）、社保/保险条件、BI 到期时间、证书到期时间、相关证书续签说明、签约情况和匹配状态。人才编号使用与企业编号一致的结构，即 `RC + yyyyMMddHHmmss`；既有编号不做迁移。人才列表按以下顺序展示：人才编号、登记（更新）时间、人才姓名、联系方式、人才持证执业（职业）、专业、薪资年限、社保情况、BI 到期时间、证书到期时间、相关证书的续签、签约情况、是否匹配和操作；不展示业务员栏。身份证号继续仅在详情页展示，列表不展示。

每条人才档案只关联一张证书。录入时固定填写一张证书，不能继续添加；同一人持有多张证书时，按每张证书分别新增人才档案，允许身份证号重复。人才详情不展示“持有证书”或“签约合同”页签。

匹配状态为计算字段：存在已提交且未撤销的送证单关联时显示“已匹配”，否则显示“未匹配”。

人才基本资料不再展示或编辑档案状态。人才的签约情况为人才级计算字段：关联送证单存在“已签署”时显示“已签约”；无已签署但存在“已过期”时显示“已过期”；其他情况显示“未签约”。送证单仍按人才与其唯一关联证书建立精确关联，但该证书关系不在人才详情页展示。

证书不再维护证书类别。人才列表筛选仅保留关键字和证书名称；证书名称筛选和人才新增时的证书名称均支持从已入库证书名称中模糊搜索并下拉选择。

### 10.2 企业库

企业库用于维护客户企业及其资质需求。字段包括：企业编号、登记/最后更新时间、客户名称、联系人、联系方式、需求证书（截图中的“专业”）、条件、客户性质、合同附件、合同到期日和匹配状态；不展示或录入业务员。

- 客户性质初始支持“企业客户”“纯资质客户”“其他”。
- 企业编号全局唯一，新增时由系统自动生成，企业表单不提供手工填写。
- 新增企业时需求证书为必填项，支持从证书名称库模糊搜索，也允许直接输入名称。
- 每个企业当前录入一条“需求证书 + 条件”需求行；后续可再扩展项目、区域、报价和多条需求。
- 合同附件为可选单文件，支持 PDF、图片和常见 Office 文档，最大 20 MB，可下载查看；合同到期日可选。
- 匹配状态为计算字段：存在关联送证单时显示“已匹配”，否则显示“未匹配”。
- 企业列表支持按客户名称或需求证书名称查询，并支持编辑。无关联送证单的企业可删除；已有送证单的企业不得删除，以保留业务关联。

### 10.3 送证单

送证单是企业与一至多位人才的匹配业务单据。首期不设置主管、企业经手人或审批流，统一以合同签署状态管理业务进度。

| 字段 | 说明 |
| --- | --- |
| 送证单编号 | 系统生成且唯一 |
| 关联企业 | 必填，企业库选择 |
| 证书注册单位名称 | 必填，可与客户名称不同 |
| 单位性质 | 必填 |
| 签署到期日 | 留空时为待签署；填写后系统自动计算合同状态，并作为到期提醒依据 |
| 人才明细 | 至少一行；关联人才及其持有证书、持证专业、人才报价、企业回扣/对事业业绩、直接支付金额、备注 |
| 汇总金额 | 自动汇总人才明细的已到账、待付款、直接支付、业绩与余款字段；首期允许录入并保存数值 |
| 合同状态 | 待签署、已签署、已过期 |

- 合同状态不提供手工修改：签署到期日留空时为“待签署”，填写且未到期时为“已签署”，早于当前日期时为“已过期”。保存单据及查询列表时均重新计算状态。
- 管理员可编辑单据及其人才明细，或删除单据。删除不可恢复，需要二次确认。
- “已签署”和“已过期”的送证单均纳入到期提醒中心，使用合同到期提前提醒天数配置。提醒显示送证单编号、企业名称、关联人才、到期日及剩余/逾期天数。
- 修改已签署送证单的到期日后，系统重新生成该单据的待处理提醒；删除或改回待签署时删除关联提醒。
- 同一人才允许存在历史送证记录；V2 不强制排他。
- 单据创建、编辑、删除均记录在操作日志。
- 企业与人才的列表均可跳转到相关送证单。

### 10.4 送证单列表与金额字段

送证单列表展示：送证单编号、合同状态、签署到期日、创建时间、单位性质、聘用单位名称/证书注册单位、对事业业绩总和、已到账总额、已付款总额、直接支付总额、人才明细数量及编辑、删除操作。

创建送证单时可添加多位人才。每条人才明细增加：人才报价、对事业业绩、已到账金额、已付款金额、直接支付金额和备注；单据顶部汇总这些金额。单位性质使用固定选项：中介、老客户、新客户、资质、其他。
