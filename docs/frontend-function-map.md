# 前端界面功能图

## 1. 设计目标

本图描述第一版管理员端网页的页面结构、主要区域和操作流。界面以桌面端高频录入、筛选和跟进合同到期事项为重点。

## 2. 整体信息架构

```text
登录页
  |
  +-- 管理后台
        |
        +-- 仪表盘
        |     +-- 到期提醒快捷入口
        |     +-- 最近新增人才快捷入口
        |
        +-- 人才管理
        |     +-- 人才列表
        |     |     +-- 新增人才
        |     |     +-- 筛选与导出
        |     |     +-- 人才详情
        |     |
        |     +-- 人才详情
        |           +-- 基本资料
        |           +-- 证书信息
        |           +-- 合同信息
        |           +-- 操作记录
        |
        +-- 到期提醒
        |     +-- 合同与证书提醒列表
        |     +-- 合同或证书详情定位
        |
        +-- 操作日志
        |
        +-- 系统设置
              +-- 合同与证书到期提醒设置
              +-- 证书名称配置
```

## 3. 全局布局

```text
+----------------------------------------------------------------------------------+
| Logo / 系统名称                              管理员账号 v                         |
+--------------------+-------------------------------------------------------------+
| 仪表盘             | 面包屑：人才管理 / 人才列表                                |
| 人才管理           +-------------------------------------------------------------+
| 到期提醒 [数量]    | 页面标题                                      主要操作按钮  |
| 操作日志           +-------------------------------------------------------------+
| 系统设置           |                                                             |
|                    |                     页面业务内容                            |
|                    |                                                             |
+--------------------+-------------------------------------------------------------+
```

- 左侧为固定主导航，显示合同和证书到期提醒的待处理总数量。
- 顶部显示当前管理员入口，提供退出登录操作。
- 内容区域使用面包屑返回上级页面。
- 列表页的新增和导出等主要命令放在标题右侧；行内操作放在表格最右侧。
- 所有提交、归档、忽略提醒等有状态变化的操作均需二次确认或明确的操作反馈。

## 4. 页面功能说明

### 4.1 登录页

```text
+---------------------------------------------------+
|                 建筑人才管理系统                  |
|                                                   |
| 管理员账号  [________________________________]    |
| 登录密码    [________________________________]    |
|                                                   |
|                          [ 登录 ]                 |
+---------------------------------------------------+
```

功能：

- 输入管理员账号和密码。
- 校验失败时在字段附近显示错误信息。
- 登录成功后进入仪表盘。
- 已登录用户访问登录页时直接跳转仪表盘。

### 4.2 仪表盘

```text
+---------------------------------------------------------------------+
| 仪表盘                                            数据更新时间：刚刚 |
+---------------------------------------------------------------------+
| [人才总数] [在库人才] [已签约] [未签约] [待处理到期提醒]            |
+---------------------------------------------------------------------+
| 待处理到期提醒                                  查看全部 >          |
| 类型 | 姓名 | 合同/证书 | 到期日期 | 剩余天数 | 操作               |
| 合同 | 张三 | XX 建筑公司 | 2026-04-03 | 7 天 | 查看合同           |
| 证书 | 李四 | 安全员 C 证 | 2026-03-25 | 已到期 | 处理              |
+---------------------------------------------------------------------+
| 最近新增人才                                    查看人才管理 >      |
| 姓名      主要证书        签约状态       更新时间      操作          |
| 王五      一级建造师      已签约         今天 10:20    查看详情      |
+---------------------------------------------------------------------+
```

功能：

- 顶部统计卡均可点击，跳转到带对应筛选条件的列表。
- 到期提醒区默认展示优先级最高的若干条提醒，包含合同和证书两类。
- 最近新增人才展示近期录入的档案。
- 合同已到期、即将到期等使用清晰的状态标签区分，避免仅靠颜色传达状态。

```text
+---------------------------------------------------------------------+

+---------------------------------------------------------------------+
| 关键词 [姓名 / 身份证号 / 手机号______________] [搜索] [重置]      |
```

功能：

- 支持关键词检索和多个条件组合筛选。

- 主要证书展示最多两项，超出部分显示数量提示，完整列表在详情页查看。
- 点击整行或“查看”进入人才详情。
- “编辑”进入人才编辑页；归档和删除在更多操作菜单内，均要求二次确认。删除为不可恢复操作。

```text
+---------------------------------------------------------------------+
| 签约合同                                              [新增合同]    |
+---------------------------------------------------------------------+
| 合同编号 | 签约单位 | 合同类型 | 开始日期 | 结束日期 | 附件 | 状态 | 操作 |
```

- 打开合同详情可查看附件列表；支持上传附件、下载附件、预览 PDF/图片及删除附件。删除附件需二次确认。

## 5. 核心操作流程

### 5.1 新增人才并录入证书

```text
人才管理
  -> 新增人才
  -> 填写基本资料
  -> 添加零到多条证书
  -> 保存
  -> 校验身份证唯一性和字段格式
  -> 人才详情（默认基本资料页签）
```

### 5.2 为人才签约

```text
人才列表 / 仪表盘
  -> 人才详情
  -> 签约合同页签
  -> 新增合同
  -> 填写合同起止日期与签约单位
  -> 保存
  -> 校验无其他履约中合同
  -> 人才状态自动显示为“已签约”
```

### 5.3 处理合同或证书到期提醒

```text
仪表盘 / 到期提醒导航
  -> 到期提醒中心
  -> 筛选合同或证书的待处理提醒
  -> 查看关联合同或证书
  -> 人才详情的对应页签
  -> 续约 / 解除 / 更新证书 / 标记提醒已处理
```

### 5.4 合同续约

```text
人才详情的合同页签
  -> 选择已到期或即将到期合同
  -> 续约
  -> 自动带入原合同信息
  -> 调整新合同日期和必要字段
  -> 保存
  -> 原合同标记为“已续约”，新合同为“履约中”
```

## 6. 交互和状态约定

- 危险操作如归档、删除人才、删除证书、删除合同附件、解除合同、忽略提醒，需要确认弹窗；删除人才的确认弹窗必须说明该操作不可恢复。
- 成功或失败操作使用短暂消息提示；表单校验错误紧贴对应字段。
- 表格无数据时显示明确的空状态和“新增人才”或“重置筛选”等下一步操作。
- 加载数据时展示骨架屏或加载状态，避免空白页面。
- 页面在桌面宽度下优先使用表格；较窄屏幕下允许表格横向滚动，保证字段可读性。
- 状态同时使用文本和视觉标签，确保不依赖颜色识别。

## 7. 已确认界面决策

1. 人才新增页允许同时录入多条证书。
2. 合同维护集中在“人才详情”的合同页签中，附件随合同管理。
3. 合同和证书到期提醒统一在提醒中心处理，历史处理状态可查询。
4. 导出位于人才列表并遵循当前筛选条件；导出前二次确认完整敏感字段。
5. 人才可在更多操作中物理删除，需显式二次确认，且不可恢复。
6. 证书名称由设置页管理，录入下拉的最后一项固定为“录入新证书名”。
7. 桌面端是首要使用场景，移动端保证基本可查看。
8. 合同附件限制为单文件最大 20 MB、每份合同最多 10 个附件。
9. 人才物理删除不可恢复，第一版不提供回收站。
10. 合同和证书提醒默认均提前 30 天，但可在系统设置中分别调整。
